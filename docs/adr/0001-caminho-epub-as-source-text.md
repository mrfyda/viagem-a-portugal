# Caminho EPUB as canonical source text

Two digital copies of the book exist (Caminho PT, Companhia das Letras BR).
All text extraction anchors to the Caminho EPUB: it is the original publisher
and its TOC carries section-level structure (65 entries vs CdL's flat 6
chapters). CdL is used only as a cross-check. Neither copy is committed to
the repo (copyright); pipelines read them from a local path outside the tree.
